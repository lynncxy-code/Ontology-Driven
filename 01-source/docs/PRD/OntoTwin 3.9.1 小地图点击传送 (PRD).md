# OntoTwin 3.9.1 小地图点击传送（PRD）

> 状态：开发基线
> 产品版本：3.9.1
> 作用域：`OntoTwinSync` UE5.6 运行时插件
> 前置能力：3.9 插件化只读小地图

## 1. 背景与目标

3.9 已能在人物漫游 HUD 中显示一次性俯视场景截图、人物位置与朝向。3.9.1 将小地图从只读定位工具升级为轻量导航入口：用户在小地图上预览目标，并通过双击将当前人物安全传送到同楼层可行走位置。

本版本目标：

1. 小地图启用时自动具备传送能力，不增加 Web 配置项。
2. 鼠标及 Pixel Streaming 的点击/触摸均可完成目标预览和双击传送。
3. 传送前验证地面与人物胶囊空间，避免落到屋顶、展品、非行走面或障碍物中。
4. 传送过程不改变当前视角模式和人物朝向，并提供 5 秒单步撤回。
5. 传送与路线漫游、旁白、小地图折叠和场景选取之间有明确的输入仲裁。

## 2. 非目标

- 不新增或修改后端 API、数据库、项目存储结构与 `mapping_rules.json`。
- 不在 Web 工作台新增独立传送开关；传送能力跟随既有小地图开关。
- 不保存传送历史，不跨会话恢复，不支持多级撤回。
- 不支持跨楼层传送、路径寻路、落点收藏、游戏手柄操作。
- 不重拍第二张小地图，不引入持续 SceneCapture 或导航网格依赖。

## 3. 已确认产品决策

| 项目 | 决策 |
|---|---|
| 功能开关 | 小地图开启即自动开启传送 |
| 点击规则 | 单击仅短暂预览；同一区域双击立即传送 |
| 视角 | 上帝、过肩、第一人称均可使用；小地图展开时直接可操作，无需先按 Tab |
| 落点范围 | 仅当前楼层可行走地面 |
| 遮挡处理 | 原点不可用时，在 150 cm 内寻找最近安全点 |
| 路线联动 | 传送会暂停路线并结束当前旁白；用户按 R 手动恢复路线 |
| 视角与朝向 | 保持传送前的视角模式与人物朝向 |
| 过渡 | 150 ms 淡出、位移、180 ms 淡入；减少动态效果时直接位移 |
| 撤回 | 5 秒内可“返回原位置”；只保留最近一次，返回前重新安全检查 |
| 输入设备 | PC 鼠标、Pixel Streaming 点击/触摸；不支持游戏手柄 |

## 4. 用户流程

### 4.1 正向传送

1. 用户进入人物漫游，小地图已展开。
2. 用户单击地图内部：系统将地图坐标换算到当前楼层，并显示候选目标。
3. 若原始点被占用，系统在 150 cm 半径内寻找最近安全点；反馈标记显示实际落点。
4. 用户在同一区域再次点击形成双击：系统再次验证落点。
5. 系统结束旁白、暂停自动路线，执行淡出、传送、淡入。
6. 小地图人物三角更新到新位置，显示“已传送”，并出现 5 秒“返回原位置”按钮。

### 4.2 撤回

1. 用户在 5 秒内点击“返回原位置”。
2. 系统以原位置为目标重新进行同楼层地面与胶囊安全验证。
3. 验证通过则使用相同过渡返回；验证失败则留在当前位置并显示局部错误。
4. 无论成功或超时，撤回入口消失；撤回本身不生成新的撤回记录。

### 4.3 失败

- 地图坐标无法反投影、没有合格地面、150 cm 内没有安全胶囊空间、角色或小地图状态失效时，不移动人物。
- 错误只显示在小地图局部反馈中，不弹系统模态框，不阻断其他漫游能力。

## 5. 交互与视觉

### 5.1 有效点击区

- 仅展开完成后的底图圆角矩形内部可传送。
- 边框、外部透明区域、圆角裁切以外区域以及右上角折叠按钮不触发传送。
- 折叠状态只保留地图图标，点击图标只负责展开。
- 地图交互控件消费点击；装饰层保持 `SelfHitTestInvisible`。

### 5.2 单击与双击

- 鼠标使用 Slate 双击事件；触摸使用 0.45 秒时间窗与 18 逻辑像素距离阈值识别第二次点击。
- 第一次点击只预览，不改变人物位置。
- 第二次点击必须与第一次位于同一目标区域；否则作为新的第一次点击。
- 地图点击不透传到上帝视角的三维实例选取。

### 5.3 反馈

- 有效原始落点：显示目标标记和“可传送”。
- 自动修正落点：目标标记移动到实际安全点，并显示“已调整至附近安全位置”。
- 无效落点：显示“该位置不可到达”。
- 成功：显示“已传送”，同时显示“返回原位置”。
- 反馈为瞬时状态，不使用持续玻璃动画；减少动态效果时不执行位移动画和相机淡变。

## 6. 技术方案

### 6.1 组件职责

| 组件 | 职责 |
|---|---|
| `UOntoTwinMinimapWidget` | 地图有效区命中、鼠标/触摸双击识别、目标与状态反馈、撤回按钮 |
| `UOntoTwinRoamingHUDWidget` | 将小地图 Widget 与交互管理器连接，转发反馈状态 |
| `UTwinInteractionManagerComponent` | 反投影、安全落点、输入仲裁、路线/旁白联动、传送与撤回状态机 |
| 既有 `USceneCaptureComponent2D` | 继续提供一次性底图与投影矩阵；不增加捕获频率 |

### 6.2 地图坐标反投影

1. Widget 将有效区内逻辑坐标归一化为 UV `[0,1]`。
2. 管理器用既有 `MinimapCaptureSize` 转换成捕获像素坐标。
3. 使用 `MinimapViewProjection` 的逆矩阵将像素反投影为世界射线。
4. 射线先与人物当前脚底高度平面相交，取得目标 XY；该点只是地面检测的水平种子，不直接作为最终传送点。

此链路复用小地图截图的同一投影矩阵，因此自动包含 `TwinMinimapAnchor_All` 的透视/正交参数与每边裁剪比例。

### 6.3 同楼层安全落点

对原始 XY 及候选偏移执行：

1. 从当前参考脚底高度上方 150 cm 向下 300 cm 进行多重射线检测。
2. 只接受法线 Z 不低于既有运行路线阈值、且碰撞响应会阻挡 Pawn 的表面。
3. 只接受与参考脚底高度差不超过人物一步高度容差的表面，并通过 `CharacterMovement::IsWalkable` 复核；排除屋顶、展台表面和跨层落点。带 `OntoTwinNoTeleport` Actor/Component 标签的表面始终拒绝。
4. 在命中地面上方按当前人物胶囊半高放置胶囊，执行 Pawn 阻挡测试。
5. 原始点无效时，以 50/100/150 cm 半径、等角度采样候选点，选择距离原点最近的安全点。
6. 忽略人物自身、当前路线、运行时路线、小地图锚点和场景管理 Actor。

### 6.4 传送状态机

```text
Idle
  -> PreviewValid / PreviewAdjusted / PreviewInvalid
  -> FadingOut
  -> Moving
  -> FadingIn
  -> UndoAvailable (5 s)
  -> Idle
```

- 任一时刻只允许一个传送事务。
- 双击执行时必须重新验证，不直接复用预览结果。
- 位移使用 `TeleportPhysics`，不扫掠；安全胶囊验证承担阻挡保护。
- 位移前停止 CharacterMovement 的当前速度，但不修改 Actor 旋转。
- 传送前调用路线 `PauseByUser()` 并结束当前旁白；不自动恢复路线。
- 正向成功后记录传送前 Transform；下一次成功正向传送会覆盖旧记录。

### 6.5 输入仲裁

- 上帝视角本身已有鼠标，地图可直接操作。
- 小地图展开时，所有漫游视角均可直接操作；仅在按住右键观察期间暂停地图点击。
- 地图 PointerEvent 被消费时，管理器在同帧屏蔽场景 Select Action，避免一次点击同时选择三维实例。
- Pixel Streaming 合成鼠标事件与原生触摸事件共用相同 UV、安全验证和事务逻辑。

## 7. 状态与数据

全部状态只存在于当前 UE 运行会话：

- 最近一次地图 PointerEvent 时间；
- 最近一次触摸位置与时间；
- 当前预览 UV/反馈类型；
- 是否正在传送、待执行 Transform；
- 最近一次正向传送的原始 Transform；
- 淡出计时器与 5 秒撤回计时器。

退出漫游、关闭小地图、热重载或组件销毁时必须清理计时器、反馈、撤回记录与相机淡变。

## 8. 性能与安全

- 小地图仍为进入漫游时的一次性捕获；传送不触发重新截图。
- 安全查询只在单击预览、双击确认和撤回时执行，不在 Tick 中执行。
- 单次最坏候选数为 37 个，每个候选只进行地面查询和胶囊阻挡查询。
- 不信任 UI 预览结果；实际位移前总是重新验证。
- 落点无效时不得改变位置、旋转、视角模式或路线状态。

## 9. 验收标准

### 9.1 功能

- [ ] 小地图开启后无需额外配置即可使用传送。
- [ ] 单击只显示预览，双击同一区域才传送。
- [ ] 底图外、边框、圆角外和折叠按钮不会触发传送。
- [ ] 小地图展开后，上帝、过肩、第一人称均可直接操作；按住右键观察时不误触发。
- [ ] 点击地图不同时触发三维实例选取。
- [ ] 平整可行走地面可准确传送，人物朝向和当前视角不变。
- [ ] 屋顶、展品、非 Pawn 阻挡表面及胶囊被占用位置被拒绝。
- [ ] 原点受阻但 150 cm 内有安全点时，反馈与实际落点一致。
- [ ] 传送后路线暂停、旁白结束，按 R 可手动恢复路线。
- [ ] 5 秒内可返回；返回前会重新安全检查；只保留一次撤回。
- [ ] 鼠标与 Pixel Streaming 点击/触摸均能工作。

### 9.2 体验与稳定性

- [ ] 标准模式过渡为约 150 ms 淡出和 180 ms 淡入。
- [ ] 减少动态效果模式直接位移，无残留黑屏。
- [ ] 折叠/展开、退出漫游、关闭小地图、热重载时无残留按钮或计时器。
- [ ] 失败仅显示局部中文反馈，不阻断场景其他操作。
- [ ] Development Editor 构建通过，且无新增运行时 Warning/Error。

## 10. 发布与回滚

- 发布只替换 `OntoTwinSync` 插件源码并重新构建项目；无需后端迁移。
- 上线前备份目标项目中所有将被覆盖的插件文件。
- 若出现输入或落点回归，可回滚 Widget/HUD/Manager 相关文件；3.9 只读小地图仍可独立工作。
