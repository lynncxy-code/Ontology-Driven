# 4.8 独立 MVP 试验与高保真界面

> 后续已新增与原 Nexus 页面联通的独立测试环境：`http://127.0.0.1:5148/nexus`，见 [联通测试说明](INTEGRATION.md)。下文 5048／5049 是早期独立内存原型，不是当前推荐的联通体验入口。

分支：`feat/ontotwin-4.8-mvp`。对应 PRD v0.10.0。

## 运行

在本目录执行：

```powershell
python server.py --demo --port 5048
```

浏览器访问 `http://127.0.0.1:5048`。不带 `--demo` 则从空环境初始化开始，可用另一个端口单独体验。只有本机回环监听，不访问正式 5000 服务。

演示账号：`admin / DemoAdmin2026!`、`engineer / DemoEditor2026!`、`viewer / DemoViewer2026!`。这些是公开样例，不得用于生产。数据只存在进程内存，重启即清空；不要输入真实密码或业务数据。

## 当前可验证

- 黑白灰组织信息／成员管理高保真页面、初始化、登录与首登改密。
- 新增成员、启停、项目编辑授权、编辑者自主建项目、新项目全厂查看。
- 集团信息导出与空环境导入；不携带账号密码或授权。
- 工程＋场景独立绑定，模拟客户端切场景，单项目连接互斥和 60 秒超时。
- 同名对象按项目分别保存，版本冲突拒绝、撤权立即阻止保存。

页面顶部明确标为隔离实验。右侧组织关系只显示本地工厂，不伪造三厂实时在线目录。

## 不代表已完成

这不是接入正式系统的完整 4.8，也不是生产认证实现：没有正式持久化、密码重置／维护恢复、登录限流、会话寿命、完整审计日志、旧项目授权迁移、全部业务接口鉴权及 UI 嵌入。试验模型仅支持新建公开项目，不得作为已有私有项目的过滤实现。

场景页是请求模拟器，不是 UE 插件：尚无真实场景发现、心跳、退出释放、UE 应用回执、未保存切场景保护及插件联调。不应把模拟按钮当作最终让用户手填场景标识的交互。

正式下一步需要：确认生产身份／场景路由及存储迁移技术方案；明确 UE 工程修改交接；将本模型的行为测试转为正式接口和真实 UE 双场景验收。不得直接把试验账号体系当作保护现有生产端点的安全边界。
