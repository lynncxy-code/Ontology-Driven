## 🎯 关键决策点

### 决策1：选择布局工具

```
内容特点分析
    ↓
内容量是固定的还是可变的？
    ├─ 固定数量 → 使用 .grid-fixed-2/3/4/5
    └─ 可变数量 → 使用 .grid-dynamic
    ↓
内容高度是否一致？
    ├─ 高度一致 → 使用标准网格
    └─ 高度不一 → 使用 .masonry
    ↓
是否有主次之分？
    ├─ 有主次 → 使用 .grid-master-detail
    └─ 无主次 → 使用标准网格或 flex
```

### 决策2：选择使用方式

```
项目复杂度分析
    ↓
需求与examples匹配度
    ├─ 高度匹配 → 方式1：完整参考
    │   └─ 保持结构，修改内容
    ├─ 部分匹配 → 方式3：混合模式（推荐）
    │   └─ 以案例为基础，灵活增删
    └─ 不匹配 → 方式2：模块化组装
        └─ 提取模块，重新组合
```

### 决策3：响应式策略

```
内容重要性分析
    ↓
所有内容都重要吗？
    ├─ 全部重要 → 全部保留，移动端堆叠
    ├─ 有主次之分 → 核心优先，次要隐藏/折叠
    └─ 分层展示 → 使用优先级响应式
        ├─ .priority-always（始终显示）
        ├─ .priority-md-up（中屏+显示）
        └─ .priority-lg-up（大屏显示）
```

## 📋 实战示例

### 示例1：产品特性展示页面

**需求**：展示8个产品特性，需要响应式设计

**流程**：
```
1. 分析内容类型 → 产品展示 → 视觉优先布局
2. 选择结构参考 → website-complete.html
3. 确定资源落点 → 将 lingjing-core-website.css 放入调用方项目样式目录
4. 读取结构参考 → 提取卡片模块
5. 构建布局 → .grid-dynamic（可扩展）
6. 响应式 → 自动堆叠
7. 验证样式入口与页面结构 ✓

```

**代码**：
```html
<div class="grid-dynamic grid-dynamic-3 gap-lg">
  <div class="card">特性1</div>
  <div class="card">特性2</div>
  <!-- 可以随时添加更多 -->
</div>
```

### 示例2：B端数据管理系统

**需求**：数据表格 + 侧边栏，主从布局

**流程**：
```
1. 分析内容类型 → 数据信息 + 主从关系
2. 选择布局 → .grid-master-detail
3. 选择结构参考 → b-system-complete.html
4. 确定资源落点 → 将 lingjing-core-b-system.css 放入调用方项目样式目录
5. 提取表格和侧边栏模块
6. 组合为主从布局
7. 响应式 → 移动端垂直堆叠
8. 验证样式入口与页面结构 ✓

```

**代码**：
```html
<div class="grid-master-detail">
  <aside class="sidebar b-sidebar">
    <!-- 侧边栏导航 -->
  </aside>
  <main class="main-content">
    <div class="advanced-data-table">
      <!-- 数据表格 -->
    </div>
  </main>

</div>
```

### 示例3：内容营销文章

**需求**：长文阅读，流式布局

**流程**：
```
1. 分析内容类型 → 文章内容 → 流式阅读布局
2. 选择布局 → .flex-col（垂直堆叠）
3. 选择结构参考 → website-complete.html
4. 确定资源落点 → 将 lingjing-core-website.css 放入调用方项目样式目录
5. 提取内容容器和排版样式
6. 构建流式布局
7. 验证样式入口与页面结构 ✓

```

**代码**：
```html
<main class="container flex-col gap-lg">
  <article class="content-section">
    <h1>文章标题</h1>
    <p>正文内容...</p>
  </article>
</main>
```

## 🚀 快速参考

### 常用布局工具

| 工具类 | 用途 | 响应式 |
|--------|------|--------|
| `.grid-dynamic` | 自适应网格 | 自动堆叠 |
| `.grid-fixed-2/3/4` | 固定列网格 | 自动单列 |
| `.grid-master-detail` | 主从布局 | 垂直堆叠 |
| `.masonry` | 瀑布流 | 自动优化 |
| `.flex-col` | 垂直堆叠 | 天然响应式 |
| `.flex-row` | 水平排列 | 移动端换行 |

### 内容类型映射

| 内容类型 | 布局策略 | 响应式 |
|---------|---------|--------|
| 产品展示 | `.grid-dynamic` + `.card` | 自动适应 |
| 数据列表 | `.grid-fixed` + `.table` | 自动单列 |
| 文章内容 | `.flex-col` + `.content-section` | 天然响应式 |
| 操作面板 | `.form-group` + `.action-bar` | 堆叠+折叠 |
| 详情页面 | `.grid-master-detail` | 垂直堆叠 |
| 图文混排 | `.masonry` | 自动优化 |

## 📝 总结

LingJing Core v3.0 的核心理念是：**内容驱动布局**。

关键点：
1. ❌ 不要让内容去适应固定的布局结构
2. ✅ 根据内容特点选择合适的布局策略
3. ✅ 使用动态网格等灵活工具
4. ✅ 保持内容完整性，不因布局删除信息
5. ✅ 响应式行为符合内容重要性

通过这套灵活的工作流程，AI工具可以根据实际内容智能地构建页面，而不是死板地复制模板，从而生成更高质量、更符合实际需求的项目。
