💡 网站顶部导航（当前页面正在使用）

本页面顶部的导航栏使用 .website-nav + .website-nav-glass 组件， 图标使用 Lucide Icons

查看代码示例 
<nav class="website-nav website-nav-glass">
  <div class="website-nav-container">
    <div class="website-nav-brand">
      <a href="#" class="website-brand-logo">
        <i data-lucide="grid-3x3" class="website-logo-icon"></i>
        <span class="website-brand-text">公司名称</span>
      </a>
    </div>
    <div class="website-nav-links">
      <a href="#" class="website-nav-link active">首页</a>
      <a href="#" class="website-nav-link">产品</a>
      <a href="#" class="website-nav-link">关于</a>
    </div>
    <div class="website-nav-actions">
      <button class="website-btn-outline">登录</button>
      <button class="website-btn-primary">注册</button>
    </div>
  </div>
</nav>

<!-- 必须初始化Lucide图标 -->
<script>
  lucide.createIcons();
</script>
