# 样例数据 —— 走一遍真实的写链路

这套数据让你在 AI 里**真的建出一个类型库、真的解析一张 CAD**，不再只是空预览。已在真后端实测通过。

## 文件

| 文件 | 用途 |
| :-- | :-- |
| `objectdef.csv` / `linkdef.csv` / `linksourcetype.csv` / `linktargettype.csv` | 本体**必须**的 4 张表（货架 / AGV搬运车 / 料箱 + 存放/搬运 两条关系） |
| `propertydef.csv` / `hasproperty.csv` | 可选：属性（状态 / 容量） |
| `demo.dxf` | 一张小 CAD 图（含 5 个实体），用来测 CAD 解析 |

## 测试序列 A：建一个真实的类型库（已实测，产出 3 个真类型）

在 AI 客户端里依次说（把路径换成你解压后的实际路径）：

| # | 你说 | 预期 |
| :-- | :-- | :-- |
| 1 | 把这几个 CSV 导入本体：`.../sample-data/objectdef.csv`、`linkdef.csv`、`linksourcetype.csv`、`linktargettype.csv`、`propertydef.csv`、`hasproperty.csv` | 导入成功，解析出 3 个节点、2 条关系 |
| 2 | 看看刚导入暂存的图谱 | 3 节点 2 边（货架/AGV/料箱） |
| 3 | 把它发布成数据集，名字叫「样例仓库」 | 返回新数据集 id |
| 4 | 激活「样例仓库」这个数据集 | 切换成功 |
| 5 | 当前项目有哪些设备类型？ | **货架、AGV搬运车、料箱** ← 你导入的真类型 |
| 6 | 画出当前项目的语义图谱 | 3 节点 + 存放/搬运 两条边 |
| 7 | 测完，激活回 demo | 收尾 |

第 5 步看到「货架/AGV搬运车/料箱」= 本体导入写链路（import→publish→activate）**真跑通了**。

## 关于「铸造出真实例」

要让 `mint_instances` 产出**真实例**（进而 `list_instances`/`set_instance_state`/快照都有真数据），需要先有「已绑定的构件」，而构件要经过 **CAD 标定 → 存构件 → 绑定** 这条更细的链。当前 30 个工具覆盖了核心动词，但 CAD 工作台里最细的几步（块类型审核、构件落库的完整编排）属于进阶流程，用简单提示词不一定能一把走通。

**想把「铸造真实例」也打通**，跟我说 —— 我可以补一份现成的「构件 payload + 逐步走通脚本」，让你从激活样例项目直接 save_components → 绑定 → 铸造出几个真实例。
