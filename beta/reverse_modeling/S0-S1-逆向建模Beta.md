# 逆向建模 Beta · S0/S1 方向说明

> 状态：低介入试验方向，未占用正式 PRD 编号，尚未合并 OntoTwin 主线。

## S0：秘书理解

### 事实

- 本地已有 Hunyuan3D-2mv 多视图模型与独立启动脚本，生成接口可接收前、后、左、右 1–4 个视图。
- 参考图中的 OntoTwin 导航为白底、黑字、灰色分组和线性图标；“模型工坊”已有“CAD 一键成模”和“坐标标定”。
- 本次只是验证新能力入口和统一交互外观，所有产物必须留在 `beta`，不得影响 OntoTwin 主工具。

### 用户结果

用户无需理解底层模型和 Gradio 页面，能从 OntoTwin 风格的“模型工坊 / 逆向建模”入口完成：上传多视图参考 → 选择结果类型 → 生成 → 三维检查 → 导出。

### 产品判断

“逆向建模”在此阶段定义为 AI 辅助的多视图近似建模，不承诺尺寸精度、拓扑质量或工程可制造性。正面是主参考，后、左、右用于减少遮挡面的猜测；页面应保留原服务能力，同时明确输入一致性和结果边界。

## S1：方向设计

### 目标

- 验证 OntoTwin 导航体系能否自然承载 AI 逆向建模入口；
- 在不修改生成引擎的前提下，完成可操作的端到端网页原型；
- 让默认路径只暴露必要选择，高级参数可展开且可恢复默认值；
- 对服务离线、生成失败和导出失败给出可恢复反馈。

### 范围

- 独立复制 OntoTwin 侧边栏视觉，在“模型工坊”下增加并选中“逆向建模”；
- 前、后、左、右四视图上传，正面必需，其余可选；样例默认填入正面；
- 本地服务状态、生成进度、失败重试；
- 生成结果的交互式三维预览、统计信息和文件下载；
- GLB/OBJ/PLY/STL 导出及现有简化选项；
- 侧栏收起、响应式布局、键盘焦点、空态与轻提示。

### 非目标

- 不修改 OntoTwin 现有路由、HTML、后端数据结构或权限体系；
- 不修改或重新加载 Hunyuan3D 模型，不建设任务队列；
- 不提供尺寸标定、CAD 参数化、工程级拓扑修复或质量承诺；
- 不自动判断多张图片是否确属同一对象、同一状态或同一比例；
- 不直接发布、合并主线或作为正式版本编号。

### 主流程

1. 页面检查本地生成服务；离线时保留配置并给出启动指引。
2. 用户至少上传正面视图，并可补充后、左、右视图；页面校验格式、大小与可读取性。
3. 用户选择“仅几何”或“几何 + 纹理”；可选去背景和高级参数。
4. 用户开始生成；同一页面显示处理中状态，避免重复提交。
5. 成功后在原服务提供的三维查看器中旋转、缩放和检查结果。
6. 用户下载直接结果，或选择格式和简化选项后创建导出文件。
7. 失败时保留输入和参数，允许修改后重试。
8. 若混元已生成文件但 Beta 未保留任务状态，可恢复最近一次本地结果，再继续下载或转换导出。

### 状态与边界

- 服务：检查中 / 可用 / 离线；
- 输入：0–4 视图 / 缺少正面 / 可提交 / 不可读取；
- 任务：待开始 / 排队或生成中 / 成功 / 失败；
- 预览：空 / 加载 / 三维结果 / 网格信息；
- 导出：不可用 / 配置就绪 / 处理中 / 可下载 / 失败。

前端只通过本机桥接服务调用现有 Gradio 命名端点，并将四个方向按固定语义位置映射到 Hunyuan3D-2mv。若 8081 运行的是单图模型，页面必须识别并阻止误提交。运行时文件写入 Beta 自己的 `runtime` 目录，不写回生成引擎或主工程。

### 验收口径

- 从独立启动入口打开页面，侧栏结构与参考图一致且“逆向建模”位于模型工坊并处于选中态；
- 不启动 Hunyuan3D 时，页面明确显示离线且不丢失用户已选图片和参数；
- 默认显示正、后、左、右四个上传位；缺少正面时不可提交，补充其他方向后显示已添加数量；
- 连接单图服务时明确提示需要 Hunyuan3D-2mv，不能把多视图误送入单图模型；
- 成功结果可以在页面内进行三维交互，并可下载直接结果；
- “生成完成但未返回文件”可以通过恢复最近结果重新建立文件关联，无需再次生成；
- 选择导出格式后能调用原有导出能力，成功文件可下载；
- 无原生弹窗、无蓝色主强调、无大面积状态色；
- 停止 Beta 服务或删除 Beta 目录不会改变 OntoTwin 主工具与 Hunyuan3D 源码。

### 风险与版本策略

- 生成时长与显存占用由本地模型决定，页面只呈现状态，不能承诺实时完成；
- 未提供的方向仍会由模型推断；多张图片若比例、状态或上下方向不一致，会增加结构误判；
- Hunyuan3D Gradio API 若升级，桥接参数可能需要同步验证；
- 仅当总经理明确验收方向后，再扫描现有 PRD/实施/验收文档并确认正式编号及主线归属。
