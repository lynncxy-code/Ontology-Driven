# OntoTwin ZHHZ 基础操作说明

适用版本：OntoTwin ZHHZ __RELEASE_DISPLAY_VERSION__ 一体化客户版  
适用对象：日常使用 ZHHZ 三维程序和 OntoTwin 控制后台的操作人员

本说明只介绍安装完成后的日常操作。首次安装、Windows 功能启用和故障部署请参阅同目录下的 `Deployment-Guide.md`。

## 1. 每日启动

1. 双击桌面的“灵云智”。
2. 单击一次“启动系统”。
3. 等待控制中心显示后台已经就绪。系统随后会启动 ZHHZ 三维程序，并在默认浏览器打开 OntoTwin 控制台。
4. 如果浏览器没有自动打开，单击“打开控制台”。控制台本机地址为 `http://127.0.0.1:5000/nexus`。

首次启动需要准备后台设备，耗时会比日常启动长。启动过程中不要反复单击“启动系统”，也不要强制关闭控制中心。

## 2. 控制中心按钮

| 按钮 | 用途 |
| --- | --- |
| 启动系统 | 启动后台、ZHHZ 三维程序和 OntoTwin 控制台 |
| 停止系统 | 关闭 ZHHZ 三维程序并安全停止后台 |
| 打开控制台 | 用浏览器打开本机 OntoTwin 控制台 |
| 立即备份 | 备份项目数据库和项目文件；重要修改后建议执行一次 |
| 刷新状态 | 重新检查后台和 ZHHZ 程序的运行状态 |

控制中心日志区会显示当前步骤和错误信息。遇到问题时，请先保留完整日志或截图。

## 3. OntoTwin 控制台

- 控制台用于查看和维护 ZHHZ 项目的语义图谱、实例、模型资产、坐标、场景交互和信息面板配置。
- 修改配置后，应使用页面上的保存或应用按钮，并确认成功提示后再切换页面或数据库。
- 切换数据库后，请等待页面加载完成再继续操作。
- ArtStudio 模型库需要能够访问配置的资产库地址；如客户网络不可用，相关在线资产功能可能暂时不可用。
- __RELEASE_RC__ 为本机一体化版本，控制台默认只在本机访问；Pixel Streaming 和实时 WebSocket 未启用。

## 4. ZHHZ 三维程序常用操作

先用鼠标单击三维画面，使键盘和鼠标焦点进入 ZHHZ 窗口。

### 4.1 人物漫游

| 操作 | 功能 |
| --- | --- |
| `F7` | 进入或退出人物漫游 |
| `V` | 在第一人称、过肩视角和全局视角之间切换 |
| `W` `A` `S` `D` | 近身视角下移动人物；全局视角下平移相机 |
| `Q` / `E` | 全局视角下向下或向上移动相机 |
| 按住鼠标右键并移动 | 在全局视角下转动观察方向 |
| 鼠标左键 | 选择支持交互的对象并打开信息面板 |
| `Tab` | 打开或收起漫游操作面板 |
| `Esc` | 按当前界面层级关闭信息面板或退出提示 |

自动漫游过程中按 `W`、`A`、`S`、`D` 会切换为人工接管。需要恢复路线时，单击画面中的“继续自动漫游”。

### 4.2 Runtime Editor 运行时编辑

1. 如果正在人物漫游，先按 `F7` 退出漫游。
2. 按 `F8` 进入 Runtime Editor；如果键盘环境占用了 `F8`，可尝试 `F10`。
3. 使用鼠标左键选择可编辑实例。
4. 使用画面中的移动、旋转和缩放控件调整实例。
5. 修改完成后，在 Runtime Editor 面板中保存；不需要修改时选择取消或恢复。
6. 再按 `F8` 退出 Runtime Editor。

Runtime Editor 与人物漫游互斥，不能同时使用。存在未保存修改时，请先保存或取消，再切换模式或退出。

## 5. 信息面板与输入恢复

- 在漫游画面中单击已配置的信息对象，会打开对应信息面板。
- 关闭信息面板或按 `Esc` 后，鼠标观察和 `WASD` 控制会恢复。
- 如果 `WASD` 没有反应，请依次检查：ZHHZ 窗口是否获得焦点、是否有信息面板或操作面板正在输入、是否处于 Runtime Editor，以及人物漫游是否已经启用。

## 6. 备份与关机

### 备份

1. 打开控制中心。
2. 单击“立即备份”。
3. 等待控制中心明确显示备份完成，再继续关机或退出程序。

建议在批量修改语义图谱、实例、场景坐标、模型绑定或信息面板配置后执行备份。

全新安装会自动选择可用空间不少于 60 GB 的本机固定 NTFS 磁盘保存后台虚拟机、Docker 数据、数据库和控制中心备份。USB、SD 卡、网络盘和虚拟磁盘不会被自动选作程序或数据盘。使用非系统盘时目录为 `X:\OntoTwin-ZHHZ\Data`；只使用系统盘或从旧版本升级时，目录仍为 `C:\ProgramData\OntoTwin-ZHHZ`。已有数据不会在升级时自动迁移。日常运行应让对应磁盘保持至少 20 GB 可用空间，不要手工移动或删除数据目录。

### 正常停止

1. 保存网页控制台和 Runtime Editor 中尚未保存的修改。
2. 回到控制中心，单击“停止系统”。
3. 等待日志显示停止完成后，再关闭控制中心或 Windows。

“停止系统”会先关闭 ZHHZ 三维程序，再停止后台，不会删除项目数据。不要直接删除 Hyper-V 虚拟机，也不要删除安装程序自动选择的后台数据目录。

## 7. 常见问题

### 启动系统长时间没有反应

- 首次启动可能需要数分钟，请不要重复单击。
- 单击“刷新状态”查看是否已经就绪。
- 检查后台数据所在磁盘是否仍有至少 20 GB 可用空间。旧安装通常使用 C 盘；全新安装也可能使用带有 `OntoTwin-ZHHZ\Data` 目录的非系统盘。
- 仍未恢复时，保留控制中心日志和截图后联系维护人员。

### 提示 Hyper-V Management is not enabled

按照部署文档启用 Hyper-V。安装程序要求重启 Windows 时，先重启电脑，再以管理员身份重新运行安装程序。

### 控制台打不开

先在控制中心单击“刷新状态”。后台未就绪时重新单击一次“启动系统”；后台已经就绪时，可直接单击“打开控制台”。

### F8 后无法选择对象

先按 `F7` 确保已退出人物漫游，再按 `F8` 进入 Runtime Editor。只有 OntoTwin 管理并允许编辑的实例可以被选中。

### 安装或启动报文件缺失

安装前应保持 __RELEASE_RC__ 交付目录中的安装程序、安装包、后台设备文件和校验文件完整，不要只复制单个 Setup 程序。

完整交付中含有大于 5 GB 的文件，FAT32 U 盘无法保存。请使用 NTFS 或 exFAT 介质，或先将整个交付目录复制到本机 NTFS 磁盘；不要拆分、改名或单独解压 payload 文件。

## 8. 报障时请提供

- 问题发生时间和操作步骤；
- 控制中心完整日志或截图；
- Windows 版本、显卡型号和驱动版本；
- 后台日志（如存在）：`<后台数据目录>\Logs\host-service.log`；全新安装的后台数据目录由安装程序自动选择，旧安装通常为 `C:\ProgramData\OntoTwin-ZHHZ`；
- 安装问题另附：`C:\ProgramData\OntoTwin-ZHHZ-Installer\Logs\payload-installer.log`。
