OntoTwin ZHHZ RC10.10-HF1 使用说明

适用版本：OntoTwin ZHHZ RC10.10

1. 关闭“灵云智”控制中心和 ZHHZ 运行时。
2. 双击 OntoTwin-ZHHZ-RC10.10-HF1.exe。
3. 同意 Windows 管理员权限提示。
4. 等待程序完成备份、后台更新和自动验证。

维护包只更新后台，不修改 ZHHZ.exe，不删除或重置 PostgreSQL、Neo4j 数据卷。
成功标志：程序显示“38 Types / 669 Instances”且提示热修复完成。

若失败，请保留窗口内容，并提供日志：
C:\ProgramData\OntoTwin-ZHHZ\Logs\rc10.10-hf1-update.log
