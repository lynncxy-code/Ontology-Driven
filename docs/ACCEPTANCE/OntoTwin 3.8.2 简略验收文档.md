# OntoTwin 3.8.2 简略验收文档

日期：2026-08-14  
范围：业务配置单页化、运行 Dock、F8 业务编辑、Web 非阻塞交互

## 1. 本次交付

- Web 端改为单页“业务配置台”：左侧业务、中间成员、右侧业务属性与当前选择。
- 日常配置不再要求输入实例 ID、类型 ID 或规则字段；复杂页面资源、域名、校验、版本与回滚收进“高级”。
- 新建业务只填写名称，成员通过对象列表直接勾选；“保存并应用”原子完成校验、发布和草稿同步。
- 业务可选择“聚焦业务对象 / 高亮业务对象 / 不改变场景”三种运行行为。
- “激活业务时的场景”明确只作用于业务激活；对象详情页面在当前选择中独立配置，可继承或按实例覆盖。
- UE 运行入口改为一个可收缩 Dock，使用 `Home / 空间 / 业务 / 漫游` 标签切换。
- 空间和业务改为选择即激活；场景实例单击即选中并打开对象详情，不再重复点击或点击“打开”。
- 网页保持显示时，非网页交互区域仍可操作 Dock 和场景；仅网页声明的交互区域接管鼠标。
- 进入 F8 后隐藏网页与运行 Dock；编辑面板新增“场景编辑 / 业务编辑”，退出后恢复运行状态。
- F8 业务编辑支持已选对象的三态归属：已选、部分、未选；支持仅输入名称新建业务。
- Web 与 F8 共用 revision 冲突保护，避免两处同时编辑时静默覆盖。

## 3. 目标关卡验收

### A. Web 单页业务配置

1. 打开“场景交互 → Web 交互”，确认页面直接显示“业务配置台”，没有旧的五步页面导航和“即时效果”。
2. 新建“消防巡检”，确认只需填写业务名称。
3. 在对象列表勾选两个实例，确认成员数、当前选择和右侧属性同步变化。
4. 单击一个对象，在“点击对象时打开”中选择页面，确认不需要输入实例 ID；切换回“继承已有规则”应移除实例覆盖。
5. 选择业务场景行为并关联页面，点击“保存并应用”，确认 revision 加一且运行端收到新配置。
6. 选中一个业务，确认业务列表中直接出现“删除”；点击后必须先显示影响说明，取消不产生修改，确认后仍需“保存并应用”才写入后端。
7. 同时打开另一编辑会话制造旧 revision，确认保存被阻止并保留本地修改。

### B. UE 运行 Dock

1. PIE 后按 `Tab`，确认只有一个可收缩 Dock，标签为 `Home / 空间 / 业务 / 漫游`。
2. 在“空间”选择一个分区，确认选择完成后立即切换场景范围并移动镜头，没有第二个“打开分区”按钮。
3. 在“业务”选择一个业务，确认立即按配置执行聚焦、高亮或仅网页行为。
4. 单击一个场景实例，确认一次点击即可执行 `open_detail` 绑定并向页面传入实例 ID。
5. 网页打开后，不关闭网页直接切换 Dock 标签、选择空间/业务和操作场景；确认网页非交互透明区不阻塞这些操作。
6. 点击 Home，确认关闭当前网页、恢复全场景与默认视角，并收起 Dock。

### C. F8 场景内业务编辑

1. 在 PIE 中选中一个或多个实例并按 `F8`，确认运行网页和 Dock 均隐藏。
2. 在“场景编辑 / 业务编辑”间切换，确认只有一个编辑面板。
3. 在“业务编辑”确认显示所选对象名称；混合选择应显示对象摘要，归属应显示“部分”。
4. 即使进入 F8 时业务数据尚未返回，确认同步完成后下拉框自动启用；占位文字应区分“未选对象 / 正在同步 / 没有业务”。
5. 点击业务下拉，保持至少 2 秒，确认下拉不会被逐帧刷新关闭；选择业务后归属状态正常切换。
6. 确认归属说明、同步详情与创建说明不再常驻占位，鼠标悬停对应控件时可以查看。
7. 切换业务归属或仅输入名称新建业务，确认底部出现未保存修改。
8. 点击“保存全部修改”，退出 F8 后打开运行 Dock，确认新业务或成员关系立即可用，刷新 Web 业务配置台后可见，进入 F8 前的网页按原状态恢复。
9. 再次修改后选择取消，确认业务归属回到进入 F8 前的状态。

## 4. 验收边界

- 3.8.2 改善配置和运行交互，不改变模型首次加载策略；分区流送仍属于后续阶段。
- 网页必须通过 Web Bridge 上报真实交互区域，才能实现“网页可见但不阻塞其余区域”；未接入 Bridge 的普通网页继续采用整页接管输入的兼容策略。
- 当前业务编辑以已有实例目录为基础，不在本页面编辑网页自身业务数据。
- 设备分区仍在 Web“实例绑定台 → 分区管理”中维护；F8 业务编辑不修改设备分区。
