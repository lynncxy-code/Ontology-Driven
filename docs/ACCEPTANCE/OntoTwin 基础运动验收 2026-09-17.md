# 基础运动：交付与验收

## 三步开始

1. 打开 `http://localhost:5000/ontology` 并强制刷新。选择 UE 正在同步的设备类型，进入“动态行为”，展开该设备当前实际状态（例如 `normal` 对应“正常”，不是任意选择“运行”）。
2. 在“动画 → 行为库”选择“持续旋转”，作用对象先选“设备整体”，默认 Z 轴、90 度/秒，保存动态行为。
3. 打开 `D:\tmp_ue\test0316\test0316.uproject`，进入 PIE，看该类型的实际模型旋转；改转速后保存应生效。改选“恢复原位”保存，应停止并恢复局部姿态。

不创建验收菜单。当前激活数据集保持用户选择，本轮没有切换数据集、替换地图或保存任何业务配置。Nexus 与 UE 必须使用同一项目、实例和实时状态，类型有模型并已挂载动态行为能力。

## 三个用例

| 用例 | 在类型里的操作 | 应看到 | 不应发生 |
|---|---|---|---|
| 整机基础动画 | 当前状态 → 动画 → 行为库 → 持续旋转／往复移动；调整轴、速度或行程 | 原模型运动；参数修改无需更换行为 | 新增指示杆代替模型；动画写回业务坐标 |
| 提升机门扇 | UE 内容维护者把独立门扇网格设为可移动、非物理模拟并标记 `OntoTwinMotionTarget`；开门状态选平移，作用对象选“项目预设可动部件”；关门状态选恢复原位 | 门扇按设定行程移动，设备本体不动 | 没有部件标记却移动整机；声称定时开门等于真实开度同步 |
| 传送带 | 动态材质 → 行为库 → 皮带条纹滚动；生产模型建议只给皮带网格标记 `OntoTwinBeltTarget`，选预设部件 | 内置条纹在模型 UV 上滚动；负速度反向；停用恢复原材质 | 物料被皮带效果自动搬运 |

皮带行为会临时替换原材质，不是对任意原有材质自动加入 UV 滚动。整机有多个材质时会统一替换，推荐使用预设皮带部件。门扇与机身若合并成一个网格，本轮不会自动拆分。
