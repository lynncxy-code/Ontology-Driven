# OntoTwin 3.4.2 历史迁移自由实例位置微调补丁 (PRD)

## 1. 背景

在 3.4/3.4.1 中，UE 历史 Actor 可以迁移为 OntoTwin 实例，并在 UE 侧由 `TwinSceneManager` 拉取显示。验收时发现：这些实例已经出现在 OntoTwin 的存活实例清单和 UE 场景中，但在实例运维中心点击“微调位置”时提示“找不到该实例对应的构件”。

根因不是迁移实例缺失，而是位置微调接口沿用了 CAD 流程的旧前提：只有“构件绑定后铸造的实例”才能被微调。UE 历史迁移实例没有 CAD 构件，因此应作为“自由实例”处理。

## 2. 产品定义

OntoTwin 中存在两类可被 UE 管理的实例：

1. 构件绑定实例
   - 来源：CAD/坐标标定流程。
   - 生成路径：构件 -> 绑定实例编号 -> 铸造实例。
   - 位置真源：构件的规范坐标。
   - 微调行为：写入构件，再派生更新实例状态。

2. 自由实例
   - 来源：UE 历史迁移、OntoTwin 直接铸造、未来 Runtime 拖拽创建等。
   - 生成路径：直接进入实例库。
   - 位置真源：实例自身的 `raw_state`。
   - 微调行为：直接写入实例空间状态。

历史迁移 Actor 不需要补建 CAD 构件。只有当未来明确要把它纳入 CAD/楼层标定体系时，才需要额外做“实例转构件/绑定构件”的专项能力。

## 3. 范围

### 本补丁包含

- `/api/v2/instances/<id>/transform` 支持自由实例。
- 实例页“微调位置”弹窗显示当前坐标真源模式。
- 自由实例保存位置时直接更新实例 `raw_state`。
- 构件绑定实例保持原逻辑不变。

### 本补丁不包含

- 不新增迁移分类工作台。
- 不把历史迁移实例自动补成构件。
- 不改 UE 迁移 JSON 格式。
- 不改 PG 表结构。
- 不改 Runtime 打包后拖拽功能。

## 4. 交互规则

实例页点击“微调位置”后：

- 若实例绑定了构件，显示“坐标真源：构件绑定”，保存后写入构件。
- 若实例没有构件但存在实例状态，显示“坐标真源：自由实例”，保存后写入实例状态。
- 若实例不存在，提示“找不到该实例”。

自由实例仍可显示规范坐标、UE 坐标和已配置坐标帧。规范坐标用于前端多坐标联动，保存时会被换算回 UE 坐标并写入实例自身状态。

## 5. 验收标准

1. 已迁移 UE Actor 出现在 OntoTwin 存活实例清单。
2. 选中迁移实例，点击“微调位置”，不再出现“找不到该实例对应的构件”。
3. 弹窗显示“坐标真源：自由实例”。
4. 修改 UE X/Y/Z 或旋转后保存，接口返回成功。
5. 刷新快照后，`I3D_Spatial` 中对应坐标发生变化。
6. UE 下一轮轮询后，实例位置按新坐标更新。
7. CAD 构件绑定实例仍显示“坐标真源：构件绑定”，原微调能力不退化。
