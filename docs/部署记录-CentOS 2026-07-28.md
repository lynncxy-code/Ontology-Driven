## ⚠ 服务器副本与 git 仓库的差异（关键，务必记住）

部署时因**国内网络**和**共享服务器端口冲突**，对服务器上的两个文件做了改动。
**这些改动只在服务器 `/opt/ontotwin/app`，git 仓库未改。** 下次更新代码若整目录覆盖，会冲掉它们，需重做。

### 1. `backend/Dockerfile` —— 加了 PyPI 清华镜像
原因：`files.pythonhosted.org` 直连超时，pip 装不上依赖。
```dockerfile
RUN pip install --no-cache-dir -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 120 --retries 5 -r requirements.txt
```

### 2. `docker-compose.yml` —— 改端口映射 + Linux 适配
原因：这台机器已跑 pg14 / tugraph / dataease 等一堆容器，`7687` 被 tugraph 占用。
- **去掉** db 的 `5432:5432`（避开 pg14；backend 走内网 `db:5432` 连库，不需宿主端口）
- **去掉** neo4j 的 `7687:7687`（被占；backend 走内网 `neo4j:7687`）
- **保留** backend `5000:5000`、neo4j 控制台 `7474:7474`
- `MODELS_HOST_DIR` 默认值从 Windows 的 `D:/SCC/...` 改为 `/opt/ontotwin/models`
- 加 `extra_hosts: host.docker.internal:host-gateway`（Linux 无此别名）
- neo4j 加内存上限 `heap 512m / pagecache 256m`（共享机器省资源）

> 修正后的两个文件另存于本机 scratchpad（`Dockerfile.server` / `docker-compose.server.yml`），
> 也可照上述要点重建。

## 代码传输方式（非 git clone）

首次尝试服务器 `git clone` GitHub **卡死**（150MB 走国际线，5 分钟只下 56K）。
改为**从本地走内网 tar 直传**，并排除 Nexus 用不到的大件：
```bash
tar czf - -C <本地仓库> --exclude=.git --exclude=assets/usd_cache --exclude=ue_project . \
  | ssh root@192.168.88.66 "tar xzf - -C /opt/ontotwin/app"
```
- 排除的 `assets/usd_cache`（~150MB）是 lite 线的机器人贴图，Nexus 无关。

## 日常运维（在 `/opt/ontotwin/app` 下）

```bash
docker compose logs -f backend      # 看后端日志
docker compose restart backend      # 改了挂载代码后重启进程（up 不重启）
docker compose ps                   # 状态
docker compose down                 # 停止（保留数据卷）
docker compose up -d                # 重新起（镜像已在，秒起）
```

## 更新代码的两条路

1. **本地增量 tar**（当前方式）：重传后 `docker compose restart backend`。
   - 注意：若覆盖到 Dockerfile / compose，需重做上面「差异」两项。
2. **内网 gitea**（推荐后续切换）：这台机器正跑着 gitea（`/usr/local/bin/gitea web`），
   把仓库推到内网 gitea，服务器改从 gitea clone，即可摆脱国际线，享受 `git pull` 增量更新。

## 已知边界

- 后端是 **Flask 开发服务器**（日志有 WARNING），内部演示/联调够用；对外正式生产需换 WSGI（gunicorn 等）。
- `host.docker.internal:5001` 的 floor_pulse 中间件未部署，相关代理接口会 503，不影响主功能。
- 环境依赖国内镜像源：Docker 镜像走 `/etc/docker/daemon.json` 里配置的 registry-mirrors；pip 走清华源。
