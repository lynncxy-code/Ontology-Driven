## 组件分类

Lingjing Core 提供的玻璃效果组件分为两大类：

### 1️⃣ 常规卡片组件（日常开发推荐）

适用于 **95%** 的业务场景：
- ✅ `.card-glass` - 标准玻璃卡片
- ✅ `.glass-card` - 玻璃卡片变体

### 2️⃣ 特殊场景组件（装饰性效果）

适用于 **5%** 的特殊视觉场景：
- ⚠️ `.glass-flowing` - 流动玻璃（含持续旋转动画）
- ⚠️ `.glass-frosted` - 磨砂玻璃（超强模糊）
- ⚠️ `.glass-colored` - 彩色玻璃（彩色渐变 + 旋转动画）

## 常规卡片组件

### `.card-glass` - 标准玻璃卡片

**定义位置：** `components/src/styles/components.css:31-59`

**样式特征：**
```css
.card-glass {
  background: var(--bg-glass);
  backdrop-filter: blur(16px);  /* 浅色模式 */
  border: var(--glass-border);
  border-radius: var(--radius-lg);
  box-shadow: var(--glass-shadow);
  transition: all 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

/* 顶部 1px 高光效果 */
.card-glass::before {
  height: 1px;
  background: linear-gradient(90deg, transparent, var(--glass-border-light), transparent);
}

/* Hover 效果：向上移动 4px */
.card-glass:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-hover), var(--glow-primary);
}
```

**适用场景：**
- ✅ 新闻卡片
- ✅ 产品展示卡片
- ✅ 业务功能卡片
- ✅ 表单容器
- ✅ 仪表盘组件
- ✅ 任何需要承载文字内容的卡片

**使用示例：**
```html
<!-- 新闻卡片 -->
<div class="card-glass">
  <img src="news-image.jpg" alt="新闻图片">
  <h3>新闻标题</h3>
  <p>新闻摘要内容...</p>
  <span class="date">2026-02-10</span>
</div>

<!-- 产品卡片 -->
<div class="card-glass">
  <div class="product-icon">📦</div>
  <h3>产品名称</h3>
  <p>产品描述内容...</p>
  <button>了解更多</button>
</div>
```

**实际项目使用率：** ⭐⭐⭐⭐⭐ (5/5)
- ✅ AVIC 官网：新闻卡片、业务卡片（自定义实现，遵循相同规范）
- ✅ 灵境航空：全部卡片（使用 `.glass-card` 变体）

---

### `.glass-card` - 玻璃卡片变体

**定义位置：** 通常在项目级 CSS 中定义（如 `lingjing-website/styles.css:650`）

**样式特征：**
```css
.glass-card {
  background: var(--bg-glass);
  backdrop-filter: blur(16px) saturate(1.3);  /* 增强饱和度 */
  border: 1px solid var(--border-glass);
  transition: all 200ms cubic-bezier(0.4, 0, 0.2, 1);
}

/* 顶部高光效果 */
.glass-card::before {
  height: 1px;
  background: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.3), transparent);
}

/* Hover 效果：向上移动 2px */
.glass-card:hover {
  transform: translateY(-2px);
  box-shadow: var(--shadow-hover);
}
```

**与 `.card-glass` 的区别：**
- 过渡时间稍快（200ms vs 300ms）
- Hover 位移较小（2px vs 4px）
- 可能包含项目特定的定制（如饱和度增强）

**适用场景：** 与 `.card-glass` 完全相同

**实际项目使用率：** ⭐⭐⭐⭐⭐ (5/5)
- ✅ 灵境航空：所有卡片（solution-card, product-card, tech-card, cta-card）

## 特殊场景组件

### ⚠️ `.glass-flowing` - 流动玻璃效果

**定义位置：** `components/src/styles/glass-effects.css:8-66`

**样式特征：**
```css
.glass-flowing {
  background: var(--bg-glass);
  backdrop-filter: blur(var(--blur-lg));
  position: relative;
  overflow: hidden;
}

/* 🔄 15 秒无限旋转渐变动画 */
.glass-flowing::before {
  animation: glass-flow 15s linear infinite;
  background: linear-gradient(45deg, transparent, var(--glass-overlay-medium), transparent, ...);
}
```

**⚠️ 为什么不适合常规卡片？**
1. **持续旋转动画会分散用户注意力**，不利于阅读
2. **视觉干扰严重**，用户难以聚焦卡片内容
3. **不符合内容为主的设计原则**

**✅ 推荐使用场景：**
- Hero 区域的背景装饰块
- 大型视觉区域（不含大量文字）
- 产品落地页的头图装饰

**❌ 不推荐使用场景：**
- 新闻卡片、产品卡片
- 表单容器
- 任何需要用户阅读文字的区域

**正确使用示例：**
```html
<!-- ✅ 正确：Hero 区域背景装饰 -->
<section class="hero">
  <div class="glass-flowing hero-decoration"></div>
  <div class="hero-content">
    <!-- 内容放在独立层，不在 .glass-flowing 内 -->
    <h1>欢迎来到灵境航空</h1>
    <p>智能航空解决方案</p>
  </div>
</section>

<!-- ❌ 错误：用于新闻卡片 -->
<div class="glass-flowing">
  <h3>新闻标题</h3>
  <p>新闻内容...</p>  <!-- 动画会干扰阅读 -->
</div>
```

**实际项目使用率：** ⭐☆☆☆☆ (0/5)
- ❌ 所有实际项目均未使用（仅在组件展示页演示）

### ⚠️ `.glass-frosted` - 磨砂玻璃效果

**定义位置：** `components/src/styles/glass-effects.css:72-106`

**样式特征：**
```css
.glass-frosted {
  background: var(--glass-bg-90);
  backdrop-filter: blur(24px);  /* ⚠️ 超强模糊 */
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1),
              inset 0 1px 0 var(--glass-border-medium);
}
```

**⚠️ 为什么不适合常规卡片？**
1. **24px 的模糊会严重影响内容可读性**
2. **适合作为背景层，不适合直接放置内容**

**✅ 推荐使用场景：**
- 模态框/对话框的背景遮罩
- 图片/视频上层的文字容器背景
- 需要强烈模糊效果的装饰层

**❌ 不推荐使用场景：**
- 新闻卡片、产品卡片
- 表单输入框
- 任何主要内容容器

**正确使用示例：**
```html
<!-- ✅ 正确：模态框背景 -->
<div class="modal-overlay glass-frosted">
  <div class="modal-content card-glass">
    <!-- 实际内容使用 .card-glass，获得清晰背景 -->
    <h2>对话框标题</h2>
    <p>对话框内容...</p>
  </div>
</div>

<!-- ❌ 错误：用于产品卡片 -->
<div class="glass-frosted">
  <h3>产品名称</h3>
  <p>产品介绍...</p>  <!-- 模糊过强，难以阅读 -->
</div>
```

**实际项目使用率：** ⭐☆☆☆☆ (0/5)
- ❌ 所有实际项目均未使用（仅在组件展示页演示）

### ⚠️ `.glass-colored` - 彩色玻璃效果

**定义位置：** `components/src/styles/glass-effects.css:112-152`

**样式特征：**
```css
.glass-colored {
  background: linear-gradient(135deg,
    var(--glass-overlay-light),
    var(--glass-overlay-medium),
    var(--glass-overlay-dark)
  );
  backdrop-filter: blur(var(--blur-lg));
}

/* 🔄 12 秒无限旋转彩色渐变动画 */
.glass-colored::before {
  animation: glass-color-flow 12s linear infinite;
  background: linear-gradient(45deg, transparent, var(--glass-overlay-medium), ...);
}
```

**⚠️ 为什么不适合常规卡片？**
1. **彩色背景会降低文字对比度**，影响可读性
2. **持续旋转动画 + 彩色渐变视觉冲击力过强**
3. **不适合严肃的企业级应用**

**✅ 推荐使用场景：**
- 营销落地页的特殊视觉区块
- 品牌展示区的装饰元素
- 创意项目的特殊卡片（艺术展示、活动宣传等）

**❌ 不推荐使用场景：**
- 企业官网的常规卡片
- 新闻/文章卡片
- 产品功能卡片
- 表单容器

**正确使用示例：**
```html
<!-- ✅ 正确：营销落地页特殊区块 -->
<section class="marketing-hero">
  <div class="glass-colored special-offer-banner">
    <h2>限时优惠</h2>
    <p class="price">¥199</p>
    <!-- 内容较少，视觉吸引力为主 -->
  </div>
</section>

<!-- ❌ 错误：用于新闻网格 -->
<div class="news-grid">
  <div class="glass-colored">  <!-- 视觉过于花哨 -->
    <h3>新闻标题</h3>
    <p>新闻内容...</p>
  </div>
</div>
```

**实际项目使用率：** ⭐☆☆☆☆ (0/5)

## 最佳实践

### ✅ 正确的组件选择流程

```
开始
  ↓
是否为常规内容卡片？（新闻/产品/表单等）
  ↓ 是
使用 .card-glass 或 .glass-card
  ↓
结束

  ↓ 否
是否为背景遮罩/模态框背景？
  ↓ 是
使用 .glass-frosted
  ↓
结束

  ↓ 否
是否为 Hero 装饰/营销特殊区块？
  ↓ 是
考虑使用 .glass-flowing 或 .glass-colored
（确认不干扰内容阅读）
  ↓
结束

  ↓ 否
使用 .card-glass（默认选择）
  ↓
结束
```

### ✅ 组件使用原则

1. **优先选择 `.card-glass` / `.glass-card`**
   - 适用于 95% 的场景
   - 简洁、专业、不干扰内容

2. **谨慎使用特殊场景组件**
   - 仅在确实需要强视觉效果时使用
   - 确保不会干扰用户阅读和操作

3. **内容为王**
   - 玻璃效果是增强，不是主角
   - 永远不要为了炫技而牺牲可用性

4. **性能优先**
   - 避免在一个页面使用过多持续动画组件
   - 特殊场景组件会增加 GPU 负担

## 常见错误

### ❌ 错误 1：滥用流动玻璃效果

```html
<!-- ❌ 错误：所有卡片都用 .glass-flowing -->
<div class="news-grid">
  <div class="glass-flowing">...</div>
  <div class="glass-flowing">...</div>
  <div class="glass-flowing">...</div>
  <div class="glass-flowing">...</div>
</div>
<!-- 问题：动画过多，用户眼花缭乱，无法聚焦内容 -->

<!-- ✅ 正确：常规卡片用 .card-glass -->
<div class="news-grid">
  <div class="card-glass">...</div>
  <div class="card-glass">...</div>
  <div class="card-glass">...</div>
  <div class="card-glass">...</div>
</div>
```

---

### ❌ 错误 2：在表单容器使用磨砂玻璃

```html
<!-- ❌ 错误：表单容器使用 .glass-frosted -->
<div class="glass-frosted">
  <label>用户名</label>
  <input type="text" placeholder="请输入用户名">
  <!-- 问题：模糊过强，标签和输入框难以看清 -->
</div>

<!-- ✅ 正确：表单容器使用 .card-glass -->
<div class="card-glass">
  <label>用户名</label>
  <input type="text" placeholder="请输入用户名">
</div>
```

---

### ❌ 错误 3：彩色玻璃用于企业官网

```html
<!-- ❌ 错误：严肃的企业官网使用彩色玻璃 -->
<div class="glass-colored">
  <h3>公司简介</h3>
  <p>我们是一家专业的...</p>
  <!-- 问题：视觉过于花哨，不符合企业专业形象 -->
</div>

<!-- ✅ 正确：企业官网使用标准玻璃卡片 -->
<div class="card-glass">
  <h3>公司简介</h3>
  <p>我们是一家专业的...</p>
</div>
```

## 总结

### 📊 组件使用建议分布

| 组件类型 | 推荐使用率 | 典型场景 |
|---------|-----------|---------|
| `.card-glass` / `.glass-card` | 95% | 所有常规卡片 |
| `.glass-frosted` | 3% | 模态框背景、遮罩层 |
| `.glass-flowing` | 1% | Hero 装饰、特殊视觉区块 |
| `.glass-colored` | 1% | 营销落地页、创意项目 |

### 🎯 快速决策指南

**需要常规卡片？** → 使用 `.card-glass`

**需要背景遮罩？** → 使用 `.glass-frosted`

**需要强视觉吸引？** → 考虑 `.glass-flowing` 或 `.glass-colored`（谨慎）

**不确定？** → 使用 `.card-glass`（默认安全选择）
