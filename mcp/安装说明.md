# OntoTwin MCP 安装说明

给 AI（Claude Code / Cursor / Codex 等）接入 OntoTwin 数字孪生能力。**三步装完。**

## 1. 前置

- **Python 3.10 或更高**：命令行敲 `python --version` 能显示版本，且 `python` 在 PATH 里。
- **能连到后端**：默认地址 `http://192.168.88.66:5000`（浏览器打开 `http://192.168.88.66:5000/nexus` 能出页面就说明通）。

## 2. 安装（一条命令）

解压后，在**本文件夹**里打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

**后端不在默认地址**时，加 `-NexusUrl`：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -NexusUrl http://你的后端IP:5000
```

脚本会自动：装好包 → 注册进检测到的 **Claude Code / Cursor / Codex CLI** → 装好 Claude Code 的 skill → 打印一段通用配置（给 Windsurf/Cline/Continue 等其他客户端手动粘）。

> ⚠️ **安全警告（务必读）：限制 AI 能读取的本机目录。**
> 默认**不限制** = 授予了「AI 可读取本机**任意** `.csv`/`.dxf` 文件并上传到 Nexus」的权限——某些客户端把上传工具设为自动运行时，AI 可在无人确认下读走本机任意路径的 CSV/DXF。
> 生产环境或把工具给他人用时，**务必**用 `-AllowedRoots` 把范围限死到一个目录：
>
> ```powershell
> powershell -ExecutionPolicy Bypass -File .\install.ps1 -AllowedRoots "D:\nexus-data"
> ```
>
> 脚本结尾也会再打印一次这条安全提示。

## 3. 重启客户端

装完**重启你的 AI 客户端**，就能看到名为 `ontotwin` 的 **30 个工具**，直接让 AI 用即可。

---

## 常见问题

| 现象 | 解决 |
| :-- | :-- |
| 提示脚本执行被禁止 | 就用上面带 `-ExecutionPolicy Bypass` 的完整命令 |
| 想先看脚本会做什么、不真安装 | 命令末尾加 `-DryRun` |
| 想限制 AI 只能读某个目录的文件 | 加 `-AllowedRoots "D:\某目录"`（安全强烈建议，见上方警告） |
| 工具调用超时 / 连不上 | 确认后端地址能访问（浏览器开 `<地址>/nexus`）；本机有 VPN/代理也没关系，脚本已默认绕过 |
| 客户端里看不到 ontotwin 工具 | 重启客户端；确认命令行 `python -m ontotwin_mcp` 能启动 |
| 提示找不到 python | 安装 Python 3.10+ 并勾选 “Add to PATH” |

> 更详细的多客户端配置、环境变量、DeepSeek 等模型怎么接，见 `DISTRIBUTION.md`。
